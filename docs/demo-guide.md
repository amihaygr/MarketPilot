# מדריך ההדגמה של <bdi dir="ltr"><code>MarketPilot</code></bdi>

מסמך זה הוא שער הכניסה לחבילת ההצגה. תסריט ההצגה המלא והעדכני נמצא בדף
הליווי הבא:

- [פתיחת דף הליווי בעברית](presentation/demo-day-step-by-step-he.md)

## מסלול ההצגה המומלץ

- משך ההצגה: <bdi dir="ltr"><code>15 minutes</code></bdi>.
- פתיחה: הבעיה העסקית והערך שהמערכת נותנת לסוחר.
- ארכיטקטורה: המסלול החי, המסלול המאושר והמסלול ההיסטורי.
- ראיות חיות: <bdi dir="ltr"><code>Dashboard</code></bdi>, ‏<bdi dir="ltr"><code>Kafka</code></bdi> ו־<bdi dir="ltr"><code>MinIO</code></bdi>.
- תזמור: ריצת <bdi dir="ltr"><code>Airflow</code></bdi> תחומה בזמן.
- תמיכה בהחלטה: <bdi dir="ltr"><code>Opportunity Center</code></bdi>.
- אימות היסטורי: <bdi dir="ltr"><code>Backtesting Lab</code></bdi>.
- סיום: אמינות, מגבלות והצעדים הבאים.

## כללי בטיחות להצגה

- אין לפתוח את קובץ <bdi dir="ltr"><code>.env</code></bdi> מול הקהל.
- אין להציג סיסמאות, אסימוני גישה או מפתחות <bdi dir="ltr"><code>API</code></bdi>.
- אין להפעיל ריצת <bdi dir="ltr"><code>Backfill</code></bdi> רק לצורך אפקט חזותי.
- אין להציג תוצאת עבר כהבטחת תשואה או כהמלצה פיננסית.
